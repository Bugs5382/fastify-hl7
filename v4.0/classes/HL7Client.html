    createBuilder

    • createBuilder<V extends HL7Version>(
          version: V,
          properties?: ClientBuilderOptions,
      ): HL7VersionBuilders[V]

      Create a version-pinned HL7 message builder

      Type Parameters

      • V extends HL7Version

      Parameters

      • version: V

        One of the supported HL7 versions ("2.1" - "2.8").

      • Optionalproperties: ClientBuilderOptions

        Optional builder options (date format, separators, hardError).

      Returns HL7VersionBuilders[V]

      Remarks

      Returns the node-hl7-client builder for the given HL7 version, with per-version field validation (withdrawn fields throw, backward-compatibility fields warn, segments not in that version are rejected). Chain build* methods and finish with toMessage().

      Since

      4.0.0

      Example

      const message = fastify.hl7.createBuilder("2.7")
        .buildMSH({ msh_9_1: "ADT", msh_9_2: "A01", msh_11_1: "P" })
        .buildPID({ pid_3: "MRN12345", pid_5: "DOE^JANE^A" })
        .toMessage();
